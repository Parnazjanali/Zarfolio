# زرفولیو

زرفولیو یک نرم‌افزار حسابداری تخصصی برای کسب‌وکارهای طلا و جواهر است. این برنامه به شما کمک می‌کند تا موجودی طلا، نقره و جواهرات را مدیریت کنید، فاکتورها را صادر کنید، حساب‌های مالی را پیگیری کنید و گزارش‌های دقیق دریافت کنید. زرفولیو با تمرکز بر نیازهای خاص صنعت جواهرات، مانند محاسبه بر اساس وزن، نرخ‌های نوسانی طلا و مدیریت وام‌های طلا (گیروی)، طراحی شده است.

## ویژگی‌های کلیدی
- **مدیریت موجودی**: ردیابی دقیق طلا، نقره و جواهرات بر اساس وزن، عیار و دسته‌بندی.
- **سیستم مشتریان** : افزدون مشتریان بر اساس دسته بندی 
- **صدور فاکتور**: ایجاد فاکتورهای حرفه‌ای با محاسبه خودکار نرخ‌ها، مالیات ،عیار و سنگ 
- **حسابداری مالی**: ثبت تراکنش‌های خرید، فروش، وام و پرداخت‌ها با گزارش‌های سود و زیان.
- **گزارش‌گیری پیشرفته**: گزارش‌های روزانه/ماهانه فروش، موجودی، بدهی‌ها و تحلیل سودآوری.
- **پشتیبانی از بارکد و تگینگ**: اسکن و چاپ برچسب برای جواهرات.
- **رابط کاربری پیشرفته**: قابل استفاده روی دسکتاپ و موبایل، با پشتیبانی از زبان پارسی.

## پیش‌نیازها
- **گولنگ**: نسخه 1.25 یا بالاتر
- **پایگاه داده**: PostgreSQL
- **حافظه نهان**: Redis
